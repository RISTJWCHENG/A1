# 🎬 我的个人视频网站

这是一个简单优雅的个人视频网站页面，可以嵌入并播放你托管在 Storj、Cloudflare R2、GitHub 或其他平台上的视频文件。

🌐 **在线演示（如果你已部署）**  
👉 https://你的用户名.github.io/my-video-site/

---

## 🚀 功能介绍

- ✅ 视频嵌入播放（支持 `.mp4`、`.webm`、`.mov` 等）
- ✅ 响应式设计，适配电脑与手机
- ✅ 一键下载视频
- ✅ 在新标签打开视频源
- ✅ 画中画（Picture-in-Picture）
- ✅ 静音 / 取消静音
- ✅ 重播按钮
- ✅ 播放列表切换（可自行扩展）
